# ⚙️ HydroFlo — Промышленная Гидравлика & Комплектующие

**HydroFlo** — современный веб-сайт и визуальная система управления (админ-панель) для компании по подбору, изготовлению и поставкам гидравлического оборудования, гидроцилиндров, насосов и компонентов.

---

## ✨ Особенности проекта

- 🚀 **Современный стек:** Построен на **React 19**, **Next.js (Vinext)** и **Vite** для молниеносной скорости загрузки.
- 🎨 **Индивидуальный дизайн:** Премиальное визуальное оформление с HSL-палитрой, микро-анимациями и эффектом "инженерной схемы" гидроцилиндра.
- 🗄️ **Интеграция с БД (Cloudflare D1 / SQLite):** Все продукты, этапы работ, направления и FAQ загружаются динамически из легкой базы данных через **Drizzle ORM**.
- 🔐 **Визуальная Админ-панель:** Встроенная панель управления по адресу `/admin` с авторизацией по паролю для удобного добавления, редактирования и удаления каталога товаров без программирования.
- ⚡ **Auto-Seeding:** Автоматическое заполнение базы данными по умолчанию при первом запуске.

---

## 🛠️ Стек технологий

- **Фреймворк:** React 19 / Next.js (Vinext App Router)
- **Сборщик:** Vite
- **Стили:** Vanilla CSS (Custom Design System, CSS Variables, Glassmorphic Glass UI)
- **База данных:** SQLite / Cloudflare D1
- **ORM:** Drizzle ORM
- **Деплой:** Готов для интеграции с Cloudflare Pages / Vercel

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
После этого проект будет доступен по адресу: `http://localhost:5173`

### 3. Панель администратора
- **URL админки:** `http://localhost:5173/admin/login`
- **Пароль:** задаётся переменной окружения `ADMIN_PASSWORD` (если она не задана, вход в админку запрещён)

## 📁 Структура проекта

```text
HydroFlo/
├── app/
│   ├── admin/             # Визуальная админ-панель (/admin, /admin/login)
│   ├── actions.ts         # Server Actions для авторизации и управления БД
│   ├── layout.tsx         # Главный layout приложения
│   └── page.tsx           # Главная страница (Лендинг каталог)
├── db/
│   ├── schema.ts          # Схема Drizzle ORM (продукты, факи, маршруты)
│   ├── index.ts           # Подключение к Cloudflare D1 (SQLite)
│   └── seed.ts            # Инициализация базы начальными данными
├── drizzle/               # SQL миграции базы данных
└── public/                # Статические ресурсы
```

## ⚙️ Скрипты

- `npm run dev` — запуск локального сервера разработки
- `npm run build` — сборка проекта для продакшена
- `npm run db:generate` — генерация новейших миграций базы данных через Drizzle Kit
- `npm run lint` — проверка качества кода через ESLint
